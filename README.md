# The Harper — 홈페이지 v2

더하퍼 홈페이지의 두 번째 디자인. 어두운 사진 위에 큰 세리프 제목을 두는 구성으로 새로 만들었다.

- 글과 섹션 구성은 첫 홈페이지(hy0909/the-harper)를 그대로 따른다.
- 색·서체·버튼·모서리 값은 [docs/design-system.md](docs/design-system.md)와 `src/styles/tokens.css`를 그대로 쓴다.
- 배포: GitHub Pages, `main` 브랜치 루트.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 한 장(헤더·히어로·About·Spots·Process·Area·Partners·Contact·푸터) |
| `src/styles/tokens.css` | 디자인 토큰(색·서체) |
| `src/styles/site.css` | 화면 스타일 |
| `src/site.js` | 언어 전환(KO/EN), 메뉴, 문의 폼, 지도 |
